# Features Overview - Text to Manim Video Generator

## 🎯 Core Features

### 🤖 AI-Powered Script Generation
- **Gemini AI Integration**: Uses Google's powerful Gemini AI to generate Manim scripts
- **Optimized Prompts**: Carefully crafted system prompts to minimize errors
- **Natural Language Input**: Describe animations in plain English
- **Smart Error Reduction**: Built-in guidelines to generate working code

### 🎬 Video Generation Pipeline
- **Automatic Compilation**: Seamlessly compiles Manim scripts to videos

- **Timeout Protection**: Prevents infinite generation loops
